============================================================
  CLEARCLAIM WEBSITE — COMPLETE TESTING GUIDE
  For Non-Technical Testers
============================================================

This guide will walk you through testing every part of the
ClearClaim website. You don't need to know anything about
coding or databases. Just follow the steps below!

------------------------------------------------------------
BEFORE YOU START
------------------------------------------------------------

1. Open your browser (Chrome or Safari works best)
2. Go to this address: http://localhost:3000
   (Someone will need to start the website for you first)
3. The homepage should load. If you see an error, ask a
   developer to start the server first.
4. Keep this guide open in another tab or print it out.

TIP: When you find a problem, write down:
  - What page you were on
  - What you clicked or typed
  - What happened (or what didn't happen)
  - What you expected to happen

SECTION 1 — HOMEPAGE (Public Landing Page)
============================================================

STEP 1: Look at the homepage
  - Go to: http://localhost:3000
  - You should see a dark blue page with a headline that says
    "Stop Losing Revenue. Start Billing Smarter."
  - You should see a fake dashboard on the right side
    (this is just for show — not a real dashboard)
  - You should see two buttons: "Free Consultation" and
    "See How It Works"

  ✓ PASS if the page looks professional and loads correctly
  ✗ FAIL if you see a blank page or error message


STEP 2: Check the numbers bar
  - Scroll down a little on the homepage
  - You should see a dark blue bar with 4 big numbers:
    "$2.4B+", "99.2%", "5,000+", "18 days"

  ✓ PASS if all 4 numbers are visible


STEP 3: Check the navigation menu (top bar)
  - Look at the top of the page (dark blue bar)
  - You should see: Home, Services, About, Resources
  - On the right: a "Patient Portal" button and a "Contact Us" button
  - Click on "Services" — you should go to the Services page
  - Click the BACK button in your browser to go back to homepage
  - Click on "About" — you should go to the About page
  - Go back and click "Resources" — you should go to the Resources page
  - Go back to the homepage

  ✓ PASS if all links work and take you to the right pages


STEP 4: Scroll through the full homepage
  - Scroll from top to bottom slowly
  - You should see (in order):
    1. Hero section (dark blue with headline)
    2. White bar with trust badges (HIPAA, 40+ Specialties, etc.)
    3. Dark blue stats bar (the 4 big numbers)
    4. Services section (gray background, 9 service cards)
    5. "Why Choose ClearClaim" section
    6. Specialties section (dark blue background)
    7. "How It Works" process steps (5 steps)
    8. Testimonials (3 customer reviews)
    9. Pricing (3 plans: Essential, Professional, Enterprise)
    10. Compliance section
    11. FAQ section
    12. "Ready to Get Started?" call-to-action
    13. Footer at the bottom

  ✓ PASS if all sections appear and look clean
  ✗ FAIL if any section looks broken, overlapping, or has giant blank spaces


STEP 5: Test the "Free Consultation" button
  - Click the yellow/gold "🩺 Free Consultation" button in the hero
  - You should be taken to the Contact page

  ✓ PASS if it goes to the Contact page

SECTION 7 — ADMIN PORTAL (Approve the Patient)
============================================================

Now you need to switch to the admin side to approve the patient
you just signed up.

STEP 1: Open the Admin login page
  - Go to: http://localhost:3000/admin
  - You should see an admin login form

STEP 1A: Also test the /auth/admin route
  - Go to: http://localhost:3000/auth/admin
  - One of these should happen:
    1. You see the same admin login page
    2. You are automatically redirected to /admin
  - If you see a "Page not found" error or a blank page, report it to the developer

  ✓ PASS if /auth/admin opens admin login or redirects to /admin
  ✗ FAIL if /auth/admin is broken, blank, or shows a 404 page

STEP 2: Log in as Admin
  - Use the admin credentials (ask the developer for these)
  - Typical test credentials:
    Email: admin@clearclaim.com
    Password: (ask developer)

STEP 3: Go to the Admin Dashboard
  - After logging in, you should see the Admin Dashboard
  - Look for a "Patient Portal Requests" card or a "Pending" section

STEP 4: Find and approve the patient
  - Click on "Patient Portal Requests" or go to the Patients section
  - You should see "Jane Patient" with a "Pending" status
  - Click "Approve" next to Jane Patient's name
  - A confirmation dialog may appear — click "Approve" again to confirm
  - The status should change to "Approved"

  ✓ PASS if Jane Patient is now shown as "Approved"
  ✗ FAIL if you can't find the patient or the approval button doesn't work

COMMON ISSUES AND WHAT TO TRY
============================================================

PROBLEM: "Page not found" error (404)
  WHAT TO TRY: Make sure you typed the address correctly.
  Tell the developer which link was broken.

PROBLEM: The website won't load at all
  WHAT TO TRY: The developer needs to start (or restart)
  the website server. Ask them to run it again.

PROBLEM: I submitted a form but nothing happened
  WHAT TO TRY: Check if all required fields were filled in.
  Try again and look for any red error messages.
  If still nothing, tell the developer.

PROBLEM: Admin login doesn't work
  WHAT TO TRY: Ask the developer for the correct admin
  email and password. Passwords are case-sensitive.

PROBLEM: Patient portal says "Account not approved" even after approval
  WHAT TO TRY: Log out and log back in. If still not working,
  ask the developer to check the database.

PROBLEM: A button click does nothing
  WHAT TO TRY: Try refreshing the page and doing it again.
  If it still doesn't work, note the page and button name
  and tell the developer.

PROBLEM: Images are broken (showing a small icon with an X)
  WHAT TO TRY: Note which page and tell the developer.
  This means an image file is missing.
